# MOON COMMUNITY SMP - Official Website

> **One Community • Infinite Adventures**  
> Official website for the MOON COMMUNITY Minecraft Survival Multiplayer (SMP) server.

## 🚀 Quick Start (Local)
You can directly **double-click `index.html`** in your File Explorer to open the website instantly in your default web browser (Edge, Chrome, Firefox, Brave, Safari) — no servers, terminal commands, or dependencies required!

## 🌐 GitHub Pages Hosting (100% Free)
This website is ready for GitHub Pages with **zero configuration**:

1. Create a repository on GitHub (e.g. `moon-community-smp`).
2. Push this folder to your repository:
   ```bash
   git init
   git add .
   git commit -m "Launch MOON COMMUNITY SMP website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment > Source**, select **Deploy from a branch**
   - Select branch: **`main`** and folder: **`/ (root)`**
   - Click **Save**

Your site will be live at:
`https://<your-username>.github.io/<your-repo-name>/`
